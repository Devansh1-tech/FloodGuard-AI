# FloodGuard AI

## AI Powered Flood Intelligence and Disaster Response Platform

This project automatically detects flood extent using satellite imagery and analyzes the impact on settlements, roads, hospitals, and infrastructure across Nepal's Terai region.

## Tech Stack

- React
- TypeScript
- FastAPI
- PostgreSQL + PostGIS
- Google Earth Engine
- GeoPandas
- Rasterio
- OpenCV
- Leaflet
- Gemini API

## Features

- Flood Detection
- Settlement Analysis
- Infrastructure Analysis
- Population Estimation
- Risk Assessment
- Emergency Route Planning
- Safe Shelter Recommendation
- AI Generated Disaster Report
